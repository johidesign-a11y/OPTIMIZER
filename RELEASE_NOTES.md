# Frameforge for Windows x64

Download **Frameforge-1.0.2-win.zip** below, extract all its contents, and open **Frameforge.exe**. Keep the executable together with its extracted resources. If a **Frameforge Setup 1.0.2.exe** installer is also listed below, you can use it instead.

Includes 59 free settings with descriptions, a CS2 focus profile, hardware scanning, temporary-file cleanup, approval dialogs, verified restore points, and exact-setting backups. The target profile is Intel Core i5-14600, RTX 3060, and 32 GB RAM; detected specifications come from the actual PC.

This is a preview release. Catalog/request tests and mocked transaction tests run during the Windows build; actual registry, power, restore-point, cleanup, and CS2 changes still require validation on a Windows test machine. FPS or input-latency gains have not been measured. The application is unsigned.

Every mutation requires approval. Applying system tweaks stops if a verified Windows restore point cannot be obtained. Cleanup permanently removes only approved old temporary files; settings backups do not recover deleted files.

`SHA256SUMS.txt` contains checksums for the uploaded installer and ZIP.
